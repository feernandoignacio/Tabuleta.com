# Tabuleta

Página inicial de um guia de comércios e serviços do bairro, com categorias, promoções em destaque, eventos e redes sociais.

## O que tem

- Busca por categoria: restaurante, mercado, bebidas, lanchonete, farmácia, pet shop, roupas e serviços
- Seções de promoções em destaque e de eventos e novidades
- Cabeçalho e rodapé separados em partes reaproveitáveis (`partials`)

## Tecnologias

- HTML5
- CSS3
- JavaScript (puro)

## Como rodar

Baixe ou clone o repositório e abra `pages/index.html` no navegador.

```bash
git clone https://github.com/feernandoignacio/Tabuleta.com.git
```
